# Hello_world_c
a program made in c on termux and compiled trough gcc 

this program contain his source code and his compiled version

you can use it by typing ./hw --help
if you just type ./hw output a basic hello world


you can move it to your bin folder just to have to type hw or hw --help like it was a package

usage:
./hw (basic hello world)
./hw --help (help menu)
./hw -r (rainbow mode)
./hw -o (original mode (white and cyan))
./hw -c (red, cyan, yellow, blue, purple, orange, green)
